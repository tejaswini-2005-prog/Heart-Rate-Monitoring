❤️ IoT Based Heart Rate Monitoring System

Using ESP32, Wokwi and Adafruit IO

📌 Project Overview

This project is an IoT-based Heart Rate Monitoring System developed using ESP32. The system monitors heart rate data and sends the information to an online IoT dashboard using Adafruit IO.

🛠️ Technologies Used

  • ESP32
  • Heart Rate Sensor
  • Wokwi Simulator
  • Adafruit IO
  • Arduino IDE
  • IoT and Wi-Fi

⚙️ How It Works

The heart rate sensor detects the user's heartbeat. The ESP32 processes the sensor data and sends the heart rate information through Wi-Fi to Adafruit IO. The data can then be monitored remotely using the IoT dashboard.

✨ Features

  • Real-time heart rate monitoring
  • ESP32 based system
  • Wi-Fi connectivity
  • IoT cloud monitoring
  • Wokwi simulation
  • Adafruit IO dashboard
